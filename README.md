# Student Portfolio

เว็บไซต์พอร์ตโฟลิโอของนางสาวโชติกา การะเกตุ สำหรับสมัครคณะพาณิชยศาสตร์และการบัญชี มหาวิทยาลัยธรรมศาสตร์

## เปิดเว็บไซต์

เปิด `index.html` ในเบราว์เซอร์ เว็บใช้ HTML/CSS/JavaScript โดยไม่ต้องติดตั้งแพ็กเกจ

## หน้าเว็บ

- `index.html` — หน้าปก
- `preface.html` — คำนำ
- `profile.html` — ประวัติส่วนตัวและความสามารถพิเศษ
- `experience.html` — ประสบการณ์และภาพกิจกรรม
- `thanks.html` — ขอบคุณ

แก้ข้อความและรายการประสบการณ์ใน `content.js` และวางรูปใน `assets/`
ภาพส่วนตัวใช้ `assets/CTK2.jpg` ตราโรงเรียนใช้ `assets/BUU.jpg` และตรามหาวิทยาลัยใช้ `assets/TU.png`

Google Fonts ใช้อินเทอร์เน็ต หากออฟไลน์จะใช้ฟอนต์ในเครื่องแทน
เว็บไซต์นี้เป็นพอร์ตของผู้สมัคร ไม่ใช่เว็บไซต์อย่างเป็นทางการของมหาวิทยาลัย
